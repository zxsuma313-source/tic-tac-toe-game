# 🎮 Tic-Tac-Toe Game

A simple and responsive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.

##  Features

- 🎮 Two-player game
- ⭕ O and ❌ X turn system
- 🏆 Winner detection
- 🤝 Draw detection
- 🔄 Reset Game
- 🆕 New Game
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 How To Play

1. Player **O** starts the game.
2. Players take turns placing O and X.
3. The first player to get three matching symbols in a row wins.
4. If all boxes are filled without a winner, the game is a draw.
5. Use **Reset Game** or **New Game** to play again.
